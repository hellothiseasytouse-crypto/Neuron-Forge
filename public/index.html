PROJECT NOTES

About Neuron Forge.

An independent experiment in building language technology from the ground up.

N

A collection-first model experience

The hosted edition searches the Shakespeare text files stored inside this repository and returns relevant passages. This keeps the source material inside the project and removes the unstable random-character demo that was previously on the site.

The repository also contains a separate decoder-only Transformer, tokenizer, training loop, checkpoint tools, and local training workflow for future experiments. The passage engine is not presented as a fully trained general-purpose chatbot.
