PROJECT NOTES

About Neuron Forge.

An independent experiment in building language technology from the ground up.

N

An offline FAI-centered conversation prototype

This version answers through a local conversation engine. It does not connect to Vercel AI Gateway or call an external AI API. The original Dying Ember source document is stored in the repository and is treated as the authority for the four FAI systems. Conversation history is stored in this browser's local storage and is not synced across devices. Relevant excerpts are sent to this project's own offline endpoint with each request; no third-party model provider is used.

The repository also contains a from-scratch GPT-style Transformer and training pipeline, but no trained general-purpose checkpoint is available yet. Until that model is trained, this offline prototype supports basic conversation, simple arithmetic, source-grounded answers about Dying Ember, and searches of the local Shakespeare collection. It does not pretend to have broad intelligence it has not learned.
